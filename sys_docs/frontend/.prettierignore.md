# 前端格式化工具排除清单

- 核对日期：2026-10-04

## 内容

依次排除 node_modules、dist、pnpm-lock.yaml、test-results、playwright-report。这份文件由 Prettier 的检查与写入命令读取，避免修改依赖安装产物、编译结果、自动锁文件和浏览器测试证据。

它不是 .gitignore，也不决定 Vite 打包内容、浏览器权限或 sys_docs 的文档覆盖范围。锁文件由包管理器按自身格式生成，因此虽然格式化排除，仍应作为依赖复现依据保留。

当前没有其他自定义 Prettier 配置文件，package.json 的 format / format:write 直接使用工具默认与此清单。

相关说明：[格式化脚本](package.json.md)、[锁文件说明](pnpm-lock.yaml.md)。
