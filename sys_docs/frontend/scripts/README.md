## 目录用途

目前只有 smoke.mjs，通过命令行指定的本地独立后端测试构建产物与真实 API。与浏览器测试目录不同，这条路径会真实写入合成记录、文档和偏好，因此必须由上层验收过程准备隔离数据目录和 fake 模式。

脚本不参与产品页面打包，也不由 pnpm test 自动执行；它是工程验收工具，不是用户健康业务定时任务。

## 对应文件和子目录
