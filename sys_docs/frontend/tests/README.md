## 测试分层

unit 在 Node 中替换 fetch，专测请求和流的字节/帧边界；e2e 在 Chromium 中渲染真实 UI，用 MockApi 提供合成契约，验证点击、路由、恢复、表单和布局。真实后端联调另放在 scripts/smoke.mjs，不在默认 test:e2e 的 mock 测试集中。

这些层次互补：单元测试能稳定制造单字节中文分片，浏览器测试能验证可见反馈，真实 smoke 能验证数据库与静态资源连通。三者均不等同于真实模型效果 Benchmark。

本次文档任务只核对现有测试源码，没有重新运行测试。历史通过数请以项目阶段验收记录为准，不从用例存在推导为当前新通过。
