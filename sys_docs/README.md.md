项目 README 是使用者首先阅读的操作文档；本套 sys_docs/README 是深入代码的导航。原 README 目前介绍 Phase 0–12 的工程能力、安装与启动、工作台使用、身份、会话恢复、九个健康工具、专业委派、Trace、RAG、Memory、模型配置及Benchmark命令。开头明确在线模型连接受阻，不能把离线优化当作在线能力验收。

启动部分明确 Windows 目录、uv 独立依赖、模板复制不覆盖已有配置、单 worker Uvicorn，以及先 pnpm build 再同源访问的方式。它还给出开发 Vite 代理、接口请求格式和流客户端用法。

业务部分解释 request_id 幂等、写入结果不确定、SSE 权威终态、只读专业工具、文档格式/容量限制、显式偏好句式和执行记录的隐私边界。例子属于使用契约，不应视为真实患者数据或在线服务效果证明。

Phase 12补充local_hash原始词法交集门控、Trace回调必须配对的完整性语义、29个contract/22个provider案例入口及严格可比较指纹。healthz的12只是工程阶段标识，不自动运行评测。Benchmark使用临时数据，真实模型仍需显式allow-provider。

验证部分区分离线框架/数据库测试、合成浏览器接口测试、真实临时 Uvicorn/SQLite smoke 和需显式开启的 live provider 检查。记录的阶段结果为历史事实，不代表每次阅读时重新执行。各阶段入口进一步链接 docs 下的交付与机器记录。

修改公开 API、启动方式、可选配置、部署限制或用户可见错误时，应优先同步本文件；逐个函数/模块设计放在 sys_docs，避免把入门操作文档扩展成难以使用的完整源码注释。
